## 🖼️ দৃশ্য-লাইব্রেরি (১২টি)

কবিতার চিত্রকল্প ধরে ১২টি আলাদা SVG দৃশ্য — প্রতিটি লাইনে একটি বরাদ্দ হয়
(কী-শব্দের মিল থেকে, আর পরপর দুটো লাইনে একই দৃশ্য আসতে দেওয়া হয় না)।

| দৃশ্য | কখন |
|---|---|
| `grave` কবর/মাটি | কবর, কাফন, কোদাল, ঘুমানো |
| `jasmine` ডালিম গাছ | ডালিম-গাছ, বাগান, শাখা, পাতা |
| `night` রাত/জোনকি | জোনকি, ঝিঁঝি, নিঝঝুম, চাঁদ |
| `mosque` মজিদ/আযান | মজিদ, আযান, মোনাজাত, খোদা |
| `child` স্মৃতি | ছোট ফুপু, সোনামুখ, সোনার প্রতিমা |
| `village` গ্রামীণ জীবন | হাট, লাঙল, তরমুজ, পয়সা, তামাক-মাজন |
| `river` সমুর | সমুর, নৌকা, জল, কূলু |
| `forest` বন/সন্ধ্যা | বনে, আবির, সন্ধ্যা, পাখি |
| `tears` কান্না | কেঁদে, বেদনা, আঁখিজল, অশ্রু |
| `hands` হাত/আলিঙ্গন | হাত, ধরিয়া, জড়ায়ে, বুকে |
| `time` সময়/জীবন | জীবন, দিনরাত, বছর, প্রাণ |
| `dawn` আশা/উদয় | ভেস্ত, নসিব, দূরে, ফিরে |

একই মোটিফে পড়া লাইনগুলোও **একই দেখাবে না** — প্রতিটি লাইনে ভিন্ন framing
(স্থানান্তর, ঘোরানো, স্কেল) ও ভিন্ন রঙ-তাপমাত্রা।

## 🔊 SRT সিঙ্ক — কীভাবে ঠিক করা হয়েছে

আপনার SRT-এর টাইমিং ইউনিফর্ম ছিল (প্রতিটি কিউ ৫ সেকেন্ড) — স্বরের সাথে মিলত না।
তিন ধাপে ঠিক করা হয়েছে:

1. **whisper.cpp large-v3-turbo** (লোকাল) → ৮৯ সেগমেন্ট
2. **segment → line-group DP** (ক্যারেক্টার-সিমিলারিটি স্কোর) → ১১৮ লাইনে সাজানো
3. একই সেগমেন্টে পড়া একাধিক লাইন **VAD-র সবচেয়ে লম্বা বিরতিতে** ভাগ,
   তারপর সিলেবল-অনুযায়ী সময় বরাদ্দ

ফল: **৮৪% লাইন ৩ সেকেন্ডের মধ্যে**, মিডিয়ান অফসেট ০.০৭ সেকেন্ড।
