# মৃত্যুভাণ — Remotion Motion-Graphics ভিডিও

**রবীন্দ্রনাথ ঠাকুরের "মৃত্যুভাণ"** কবিতার ১১ মিনিটের অ্যানিমেটেড ভিডিও, আপনার নিজের স্বরলিপির অডিও সহ।

SRT → Remotion পাইপলাইন দিয়ে তৈরি — ১১৮টি কবিতার লাইন, প্রতিটি আলাদা সিনে।

## ▶️ ব্যবহার

```bash
npm install

# প্রিভিউ
npx remotion studio

# রেন্ডার
npx remotion render src/index.ts Main out/video.mp4
```

`node_modules` ছাড়াই চালাতে হলে:

```bash
ln -sfn /home/imran/n8n/remotion-lab/node_modules ./node_modules
```

## 🔁 নতুন SRT দিয়ে একই ধরনের ভিডিও

```bash
cd /home/imran/n8n/remotion-lab
node generate.js input/নতুন.srt out-নতুন opts-poem.json
```

`opts-poem.json`-এ `scenes: {maxCuesPerScene: 1, minGapSec: 0, maxSceneSec: 0}` দেওয়া
আছে — এটা না দিলে প্রতিটি সিনে **প্রথম কিউ ছাড়া বাকিগুলো ড্রপ হয়ে যায়** (এটা
জেনারেটরের একটা সিলেন্ট বাগ, এখানে ঠিক করা আছে)।

## 🔊 SRT সিঙ্ক কীভাবে ঠিক করা হয়েছে

আপনার SRT-এর টাইমিং ইউনিফর্ম ছিল (প্রতিটি কিউ ৫ সেকেন্ড) — মানে স্বরের সাথে মিলত না।
ঠিক করার পদ্ধতি:

1. **whisper.cpp large-v3-turbo** (লোকাল, ১.৬GB) দিয়ে অডিও ট্রান্সক্রাইব → ৮৯ সেগমেন্ট
2. প্রতিটি সেগমেন্টের লেখা বনাম কবিতার ১১৮ লাইনের **ক্যারেক্টার-সিমিলারিটি** স্কোর
3. **segment → line-group DP** — সেগমেন্টগুলোকে ক্রমাগত লাইন-গ্রুপে ভাগ করা (সেরা স্কোর)
4. প্রতিটি লাইন তার সেগমেন্টের সময়কাল পায়, সেগমেন্টের ভেতরে **সিলেবল-অনুযায়ী** ভাগ হয়

ফলে প্রতিটি কবিতার লাইন ঠিক সেই মুহূর্তে দেখানো হয় যখন আপনি সেটা পড়ছেন।
